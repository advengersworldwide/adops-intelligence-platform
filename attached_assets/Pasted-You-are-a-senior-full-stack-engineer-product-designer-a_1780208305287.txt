You are a senior full-stack engineer, product designer, and data architect.

Build a production-ready internal SaaS web application called:

"AdOps Intelligence Platform"

This system is used by a reseller managing multiple DSP advertising platforms, clients, and buying houses.

----------------------------------------
🎯 CORE OBJECTIVE
----------------------------------------
Build a centralized platform that:
- Tracks client spend, platform costs, and profitability
- Handles multiple DSP platforms and multiple clients per platform
- Allows monthly Excel/CSV uploads from clients
- Automatically processes and maps data
- Provides a powerful analytics dashboard
- Supports internal operational decision-making

----------------------------------------
🧱 TECH STACK (STRICT)
----------------------------------------
Frontend:
- React (with Vite)
- Tailwind CSS
- ShadCN UI components
- Recharts (for charts)

Backend:
- Node.js (Express)
- PostgreSQL (via Prisma ORM)

File Processing:
- Use PapaParse or XLSX for CSV/Excel parsing

State Management:
- React Query (TanStack Query)
